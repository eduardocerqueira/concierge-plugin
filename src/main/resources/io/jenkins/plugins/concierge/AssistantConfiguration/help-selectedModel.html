The models the provider offers, fetched from its own API with the API key above once the provider, key and base URL are set. Each one shows its price per million tokens and where that price comes from:

  • reported by xAI: live, from xAI's API.
  • list price, as of a date: shipped with Concierge. Prices change, so check the provider's pricing page and override below when they do.
  • set by an administrator: from Model prices below.
  • price unknown: no source has it. You can still use the model.

Pick a model that supports tool calling. Anthropic defaults to claude-sonnet-5-5.
